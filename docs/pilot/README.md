## Pilot Package Quick Start

**For the pilot operator:**
1. Read `PILOT_ONBOARDING.md` — follow steps 1–8 in order
2. Work through `PILOT_CHECKLIST.md` — verify everything works
3. If you hit issues, check `PILOT_SUPPORT.md`
4. After 2 weeks, complete `PILOT_FEEDBACK.md` and submit to deployment team

**For the deployment team:**
1. Deploy using `PILOT_DEPLOYMENT.md`
2. Brief pilot operator on bootstrap key and base URL
3. Operator works through `PILOT_CHECKLIST.md`
4. After 2 weeks, assess against `PILOT_SUCCESS.md` criteria
5. Use `PILOT_PROFILE.md` to plan next pilot expansion

---

## Required Before Pilot Starts

- [ ] Ai-Guardian deployed and accessible at a known URL
- [ ] Bootstrap key generated and secured
- [ ] Pilot operator briefed on their admin key
- [ ] Breakglass PIN known to on-call personnel
- [ ] Backup confirmed working
- [ ] `docs/QUICKSTART.md` and `docs/API.md` available to operator
